# 通用自媒体合规核心

## 目的

本文件用于任何产品、项目和品牌的公开自媒体内容。它提供审核思维，不取代具体平台规则或法律意见。

## 一、先判断内容身份

在审核前明确：

- 发布主体：个人、品牌、产品团队、媒体、虚拟角色或代理运营方
- 内容目的：知识分享、开发记录、产品演示、招募、商业推广、客户案例、活动
- 商业关系：自有产品、付费合作、赠品、联盟佣金、无合作提及
- 素材性质：真实拍摄、真实产品截图、演示数据、概念效果、AI 生成/编辑、第三方素材
- 用户动作：阅读、评论、关注、下载、购买、报名、私信或站外联系

身份不清会让事实、广告、声明和 CTA 的判断全部失真。

## 二、五层审核

## 1. 事实层

逐项建立“主张—证据”关系：

| 主张类型 | 可接受证据举例 | 常见风险 |
|---|---|---|
| 已上线功能 | 当前可操作产品、版本说明、正式文档 | 把规划写成已实现 |
| 效果/性能 | 明确样本、条件、方法、时间范围 | 把个例写成普遍保证 |
| 用户案例 | 授权记录、真实访谈/反馈、脱敏原文 | AI 虚构或拼接用户 |
| 规模/排名 | 一手后台、官方报告、统计口径和日期 | 下载、注册、MAU 混用 |
| 价格/优惠 | 当前有效页面、时间和适用条件 | 虚假稀缺或过期信息 |
| 身份/资质 | 可核验资质、公开任职信息 | 冒充专家、官方或用户 |

审核问题：

- 这是事实、推断、愿景、示例还是营销修辞？
- 证据是否支持同样强度的表达？
- 数据是否有日期、样本、范围和口径？
- 是否省略会改变理解的条件？
- 产品是否真的可下载、购买或使用？

未知信息标为未知，禁止为了内容完整而补造。

## 2. 平台层

只使用目标平台规则包。检查：

- 内容真实性和账号身份
- AI/广告/商品/利益关系声明
- 导流、互动、抽奖和站外行为
- 自动发布、自动回复和批量操作边界
- 特定类别规则与平台发布页选项

平台经验不能自动升级为硬规则。没有目标平台规则包时，明确能力缺口。

## 3. 法律与权益层

至少检查：

- 广告语境中的绝对化、效果保证、比较性或权威背书
- 版权：图片、音乐、视频、字体、文章和软件界面
- 商标与不正当比较
- 肖像、姓名、声音和个人经历授权
- 隐私：手机号、车牌、地址、定位、订单、账单、设备标识
- 医疗、金融、法律、教育等高风险专业建议
- 未成年人、危险行为、违法商品或活动

不要把免责声明当作免死金牌。若关键事实或行为本身不合法/不真实，加一句“仅供参考”不能修复。

涉及法律解释、资质或高损失风险且证据不足时，标“需专业人工复核”。

## 4. 素材层

每项素材标注：来源、授权、真实性、AI 参与、脱敏状态、对应事实。

必须清楚区分：

- 真实产品截图 vs AI 概念图
- 真实用户数据 vs 演示/合成数据
- 真实拍摄 vs AI 合成场景
- 已上线功能 vs 设计方向
- 品牌 IP vs 模拟真人身份

AI 声明不能替代版权、肖像或产品事实核验。

## 5. 运营层

检查：

- 标题、封面与正文是否一致
- 是否搬运、洗稿或高度复刻个人表达
- 是否用虚假冲突、恐惧、稀缺、身份或结果骗点击
- 互动引导是否自然且符合平台规则
- CTA 是否真实可执行、符合产品阶段
- 是否连续硬广导致信任损耗
- 是否能明确回答用户一个真实问题

运营优化不能越过前四层。

## 三、风险分级

### P0 — 阻断

典型情况：

- 已知虚假事实、虚构用户/数据/功能/新闻
- 未获授权的敏感肖像、声音、隐私或明显侵权素材
- 违法、危险或平台明确禁止的自动化互动
- 试图规避标识、去水印、操控矩阵或冒充真人/官方
- 当前 CTA 根本不可用，却要求用户立即行动

处理：停止发布，先解决根因；不要只改几个词。

### P1 — 必改

典型情况：

- 证据不支持表达强度
- 缺少平台明确要求的声明，或未遵守用户/项目已采用的从严披露口径
- 广告、利益关系、AI 或概念效果的不透明已构成误导风险

平台仅“建议”的声明默认列为 P2 透明性建议；只有同时存在冒充真实拍摄、隐瞒 AI 身份、概念图伪装成已实现功能等独立风险时，才按对应事实升级为 P0/P1。
- 标题与内容不一致
- 导流或互动方式存在明确平台风险

处理：给出具体修订，修改后重新审核。

### P2 — 提醒

典型情况：

- 第三方经验或低置信度观察
- 语境可能引起误解但非明确违规
- 素材授权证据待归档但已有合理来源说明
- 表达、节奏、频率的运营性建议

处理：说明不确定性，让用户决定或补证据。

## 四、审核报告要求

每个风险项必须包含：

1. 原文片段或素材定位
2. 风险等级
3. 判断理由和语境
4. 证据来源等级与日期
5. 可执行的修改/补证建议
6. 是否需要重新确认或专业复核

禁止：

- 只输出命中词清单
- 把“可能限流”说成确定事实
- 用第三方词库声称平台官方禁用
- 没有证据却保证安全

## 五、公开写操作门禁

公开发布、评论、私信、关注、资料保存都要：

- 展示当前最终内容和目标账号
- 清零 P0/P1 或明确用户接受的 P2
- 获得针对当前版本的明确确认
- 执行前复核页面实际值
- 内容发生实质变化时重新确认

批量操作比单项风险更高；默认不批量执行。
