# 素材产出与自检规范

> 适用：为任何平台产出封面、大字卡、贴纸、拼图等设计素材（PIL/HTML/AI 生图均可）。小红书任务先用 `xiaohongshu-visual-editorial.md` 决定封面职责、连续页结构与原生感，本文件只负责技术出图和像素级 QA。
> 来源：真实产出踩坑沉淀（同行锚点混用、不透明素材压字、底色接缝）。用户素材与项目事实不放本文件。

## 1. 版式规格

- **平台规格先行**：按目标平台官方推荐尺寸出母图（小红书 3:4 用 1242×1656；其他平台查官方文档，不套用）。
- **母图保真**：始终按最高规格输出母图；缩略图从母图派生，禁止反向放大、禁止按当前显示场景激进缩小母图。
- **安全区**：四周留边 ≥ 画布宽度 5%；关键信息保持在中央 90%，防平台裁切与 UI 遮挡。

## 2. 对齐（最高频翻车点）

- **同行同基准**：一行内的文字、药丸、图标必须共用同一垂直基准线（统一用垂直中心锚点绘制，如 `anchor="lm"/"mm"`）；禁止左上角锚点与中心锚点混用在同一行。
- **间距相对化**：行距、块距相对字号或前一行 bbox 计算（如 `下一行中心 = 上一行bbox底 + 1.5×字号`），不硬编码绝对值；改字号不破版。
- **多行左缘**：默认统一左缘；刻意错位要有明确设计意图。
- 高亮条、下划线等装饰以文字 bbox 为基准绘制，完成后目检不截断笔画。

## 3. 分层与素材贴入

- **先文字安全区，后素材**：先排文字并量出占位，图片素材只分配剩余空间；禁止先贴大图再想文字放哪。
- **不透明素材三步**：① 紧裁剪到主体（按与背景色的差值求 bbox）；② 画布底色采样素材四角、保持一致；③ 羽化遮罩（rounded rect + Gaussian blur）贴入，消除接缝。
- **素材不得压文字**：贴入后核对素材矩形与文字 bbox 无交集。

## 4. 文字渲染

- CJK 用系统中文粗体（macOS 如 Hiragino Sans GB W6）；拉丁/数字可配等宽或圆体做点缀。
- PIL 无字体回退：缺字即豆腐块；**禁用 emoji 字符**，装饰图形用矢量绘制（圆点、勾、加号）。
- 每张图产出后目检：错字、豆腐块、描边溢出、高亮遮字。

## 5. AI 素材联动

- 使用 AI 生图/图生图素材时：记录来源、版本、提示词到当期素材清单。
- **声明联动**：笔记内出现 AI 生成视觉 → 同步触发平台 AI 声明检查（勾选平台声明 + 正文说明，见对应平台规则包）；纯排版封面不触发。
- 能用纯排版表达就不引入 AI 素材；引入前先问「这个素材是否值得一次声明」。

## 6. 出图后自检清单（逐项过，不过不出稿）

- [ ] 小图可读：生成 ≤240px 宽缩略图，主标题在信息流小图尺寸下仍可读
- [ ] 对齐：单行内垂直中心一致；多行左缘一致（刻意设计除外）
- [ ] 无遮挡：素材、阴影、装饰不压文字笔画
- [ ] 底色：贴入素材无接缝、无色差矩形
- [ ] 声明联动：AI 视觉 → 声明已写进发布包
- [ ] 版本记录：定稿前原地迭代并在素材清单记录变更；用户确认后版本号递增
- [ ] 平台编辑审核：小红书素材按 `xiaohongshu-visual-editorial.md` 评分；封面元素预算、真实证据与连续页职责已通过
